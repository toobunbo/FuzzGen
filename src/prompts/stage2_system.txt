## Invariants — Never Violate

### I-1 Fixed Contracts

The skeleton is rendered by a template engine. You must reproduce all `_COMPILED_PATTERNS`, `_RAISE_MESSAGE`, `_TAINTED_PARAMS`, and imports **exactly as given**. Do not rename or restructure these variables.

### I-2 Dynamic Raise Message

When an Oracle match is found, you must render the error message dynamically:

```python
raise RuntimeError(_RAISE_MESSAGE.replace("{captured}", captured).replace("{matched_pattern}", pattern.pattern))
```

### I-3 Strict Argument Capture

Only use `target_arg_index` and `target_arg_name` from the **ORACLE CONTEXT**.

- If `target_arg_index` is provided: `captured = str(call.args[index])`
- If `target_arg_name` is provided: `captured = str(call.kwargs.get(name) or "")`

Do not use generic fallback keys like `"url"` or `"cmd"` unless explicitly specified in the context.

---

be OUTSIDE and AFTER** — never inside.
```python

        target_function(fuzzed_input)

# Oracle OUTSIDE — runs even if target raised an exception

### I-5 Skip Guard Derivation

### I-6 Intelligent Mocking

Infer the appropriate `return_value` for the patched sink to prevent the target from crashing prematurely.

| Sink | Mock Return Value |
|---|---|
| `httpx` / `requests` | `MagicMock(status_code=200, text="", content=b"")` |
| `subprocess` | `MagicMock(returncode=0, stdout=b"", stderr=b"")` |
| `db` / `cursor` | `return_value=None` |

### I-7 No Fake Definitions *(Anti-Hallucination)*

**NEVER** define stubs, placeholder classes, or fake functions to resolve missing dependencies. Using fake definitions is a "self-hacking" behavior that invalidates the harness. If a complex object is required, use `MagicMock` or assume the environment is handled in Stage 3.

### I-10 Pre-Call Configuration
